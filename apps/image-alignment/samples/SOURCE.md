# Sample images

`reference.png` and `photo.png` are original images generated by `scripts/make_samples.py` in this repository. They are not taken from a dataset, a stock library, or another project.

The reference is a drawn poster. The photo is that poster, placed with a known perspective on a plain background, then darkened slightly and given a little noise. No third-party photograph is included.

Regenerate them from the app directory:

```bash
uv run python scripts/make_samples.py
```
