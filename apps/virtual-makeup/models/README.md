# Face landmarker model

`face_landmarker.task` is Google's MediaPipe Face Landmarker (float16, model card version 1).

- Source: https://storage.googleapis.com/mediapipe-models/face_landmarker/face_landmarker/float16/1/face_landmarker.task
- License: Apache License 2.0, the same license as MediaPipe (https://github.com/google-ai-edge/mediapipe)

`scripts/dev.sh` downloads this file if it is missing. The app forces the CPU delegate.
