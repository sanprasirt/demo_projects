# demo_projects

Monorepo of self-contained tech demos. Each app lives in `apps/<slug>/` and starts with `bun install && bun run dev`.

## Apps

| App | Description | Run |
| --- | --- | --- |
| [virtual-makeup](apps/virtual-makeup/) | Lipstick, blush, and eyeshadow on an uploaded face photo or a webcam still, using OpenCV and MediaPipe face landmarks. | `cd apps/virtual-makeup && bun install && bun run dev` |
